# F7Hub

F7Hub is a Windows technician workspace built with Python/PySide6 and SQLite. See [ROOT.md](ROOT.md) for setup and [the documentation index](Docs/19_DocumentationIndex.md) for architecture and workflows.

Run `AutoHotkey/F7Hub.ahk` with AutoHotkey v2: tap F7 to launch/focus the desktop app, hold F7 for magnetic window movement, and press Alt+F7 for the Help Desk & Interview Guide. The desktop toolbar and File menu also provide **AltF7Hub Guide**, starting or reusing the shared AHK host.

In the guide, notes/list focus enables topic letters, Up/Down wraparound navigation and Left/Right opacity adjustment (1% per press, held-key repeat, 70–100%). The existing library, editor and archive are preserved. [Guide setup and shortcuts](AutoHotkey/Troubleshooting_Sections/README.md). The guide displays reference reminders; ticket-driven topic selection remains deferred.
